# Nestling – Nest Helper (Team JARDS, AI-GNITION 2026, Problem Statement 1)

> **Fictional shop. Simulated data.** Nestling is not a real business. Every customer, order and result here is invented for the competition.

## What it is
Nest Helper is a MantaGO chatbot for a fictional baby shop, Nestling. It uses customer data to send each family one personal message at the right time (refill, size-up, milestone or win-back), lets parents reorder in one or two taps, answers questions with AI, and hands over to a real person when needed.

## Try the bot
Open `demo/demo_page.html` in Chrome and click the chat bubble (MantaGO LiveChat).

| Type this | What happens |
|---|---|
| `MENU` | Main menu |
| `DEMO` | Demo customers: shows the message each customer would get |
| `REORDER` | Reorder past items |
| `ASK` | Ask the AI a question |
| `HUMAN` | Talk to a person |
| `STOP` | Stop reminders |
